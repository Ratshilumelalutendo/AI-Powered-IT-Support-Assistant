# 🤖 AI-Powered IT Support Assistant

## 🌟 Overview
This project was developed for the **AI Skill Accelerator Programme**. It serves as a Tier 1 IT Support hub that solves the problem of repetitive technical queries and manual administrative work.

## 🚀 Key Features
- **Smart Chatbot**: Handles natural language technical queries.
- **Quick-Fix Dashboard**: One-click solutions for common network and system issues.
- **Email Generator**: Automatically drafts professional resolution updates for clients.

## 🛠️ Technology Stack
- **Language**: Python
- **Framework**: Streamlit
- **AI Logic**: Advanced Prompt Engineering for technical troubleshooting.

## 🛡️ Responsible AI
The application includes strict safety protocols, including disclaimers for hardware-related issues and clear boundaries on when to escalate to human technicians.
